# Google Calendar event template

Use a dedicated `Founder Discovery Calls` calendar when possible.

Title:

```text
[GROWTH AUTOPSY] Company Name – Founder Name
```

Description:

```text
Automation: GROWTH_AUTOPSY
Company: Company Name
Website: https://example.com
Founder: Founder Name
Founder Email: founder@example.com
Founder LinkedIn: https://www.linkedin.com/in/example
Industry: Ecommerce
Strategy Mode: auto
```

Valid strategy modes for the POC are `auto`, `case_study_only`, and
`case_study_and_strategy`. The founder email can be omitted when the founder is
included as a calendar attendee.
